# Colophon

This book is written in Markdown and built with
[content-kit](https://github.com/alpibrusl/content-kit), an open-source
toolchain for books-as-code. The manuscript lives in a repository with its
full history — [alpibrusl/prompt-to-decision](https://github.com/alpibrusl/prompt-to-decision)
— where a term-continuity linter checks that no word is used before it is
defined, and the same source renders to EPUB, HTML and PDF.

It is the fourth in a series, and the one the other three were quietly
building toward. [*Prompt to
Production*](https://github.com/alpibrusl/prompt-to-production) asks
whether you can trust the software an agent built enough to run it.
[*Prompt to Evidence*](https://github.com/alpibrusl/prompt-to-evidence)
asks whether you can trust its analysis enough to believe it. [*Prompt to
Ledger*](https://github.com/alpibrusl/prompt-to-ledger) asks whether you
can trust its financial model enough to plan around it. This one asks the
question sitting above all three: it recommends acting. Should you?
